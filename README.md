# bhavya-sharma.com (v2, one site)

One page instead of two. Every section shows the essentials first, and opens up for the full story.

- `index.html`: the whole site
- `Bhavya_Sharma_CV.pdf`: the CV the site links to
- `og-portfolio.png`: the preview image for links shared on LinkedIn, WhatsApp and so on
- `vercel.json`: clean URLs, and sends old `/me` links to the home page

To try it: create a new GitHub repo, upload these files, and import the repo into Vercel as a separate project. It gets its own vercel.app link. The domain stays on the old site until you move it.
